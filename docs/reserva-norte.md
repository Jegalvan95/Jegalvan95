# Reserva Norte

[← Volver al portafolio](https://github.com/Jegalvan95)

**Catálogo web interactivo para una propuesta de marca de carnes premium en Durango**  
Prototipo estático · HTML, CSS y JavaScript

## Trabajo desarrollado

- Identidad visual en tonos carbón, vino, oro y marfil, con emblema SVG.
- Navegación adaptable a móvil y filtros de catálogo.
- Fichas de cortes en diálogos y selección sin duplicados.
- Preparación y descarga local de una consulta con fecha.
- Navegación por teclado, foco visible y cierre de diálogos con Escape.
- Animaciones con control de pausa y respeto al movimiento reducido del sistema.

## Tecnologías

HTML semántico, CSS y JavaScript nativos, sin dependencias de terceros. Recursos gráficos locales y tipografías del sistema.

## Alcance actual

El sitio funciona como prototipo de presentación y catálogo. La selección se mantiene solo durante la sesión de la página. El formulario genera un archivo descargable: no envía consultas, registra pedidos ni procesa pagos.

Las imágenes de carne son conceptuales y generadas con IA; no representan piezas reales disponibles. Catálogo, precios, gramajes, contacto, cobertura de entrega y fotografías comerciales requieren confirmación.

## Disponibilidad

Esta ficha es pública y el repositorio de código permanece privado. La web puede ejecutarse localmente; no hay una URL pública de demostración verificada en esta revisión.
