# CROS DEV — Sitio corporativo

[← Volver al portafolio](https://github.com/Jegalvan95)

**Landing corporativa y portafolio**  
Implementación local · HTML, CSS y JavaScript

## Objetivo

Presentar los servicios y el trabajo de CROS DEV mediante una web de navegación sencilla y diseño adaptable a móvil.

## Trabajo desarrollado

- Presentación de servicios y proyectos mediante tarjetas.
- Navegación móvil, indicador de sección y acceso para volver al inicio.
- Selección de proyecto o servicio desde las tarjetas hacia el formulario.
- Validación de campos y preparación de un resumen que el visitante puede copiar.
- Preguntas frecuentes desplegables.
- Control de animaciones, alternativa de movimiento reducido y contenido accesible sin JavaScript.

## Tecnologías

HTML, CSS y JavaScript nativos. El sitio no requiere instalar dependencias ni ejecutar una compilación.

## Evidencia y estado

La documentación registra una revisión local de navegación, recursos, menú móvil, formularios y movimiento a distintos anchos. No se repitió esa validación al preparar esta ficha.

El formulario prepara y copia un resumen local; no envía solicitudes. El canal oficial de contacto y la recepción de consultas siguen pendientes. Las composiciones gráficas del portafolio son ilustraciones, no capturas funcionales de productos.

## Disponibilidad

Esta ficha es pública y el código permanece privado. No hay una URL pública de demostración verificada en esta revisión. Que un producto aparezca en la landing no significa que esté desplegado o disponible comercialmente.
